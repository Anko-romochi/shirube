# 参考元・独自実装・比較の限界

MaryCache/imozuru、固定commit `14635fb74a1f68e5c138379c3a6e4ec823b7cb59`。
https://github.com/MaryCache/imozuru/tree/14635fb74a1f68e5c138379c3a6e4ec823b7cb59

README、SKILL、fetch/chain/report/watchを静的に読み、用語・人・資料群から原典へたどる探索を学習しました。上流には異なる検索役、原文保存、未読区別、行と引用の照合、食い違いの併記、既知/新規管理があります。引用検証を初めて追加したとは主張しません。

SHIRUBEの文章・Python・テストは新規実装。上流コードは導入・実行していません。MIT表記はUPSTREAM-LICENSE.txtに保持しています。研究本文や私的レビュー写しは配布物に含めません。

|観点|固定上流で静的に確認|SHIRUBEの追加検査と限界|
|---|---|---|
|引用実在|report.pyの行近傍照合、空白正規化、省略区間順序、HTMLエスケープ|保存hashと厳密行照合。改行以外の表記差には弱い|
|原典系列|本人/まとめ等の区別、まとめから原典追跡|手動derived_fromを遡り同根を重複計上せず、循環を拒否。依存の発見や系列誤入力の訂正は自動でない|
|引用の意味|人が引用を読む。機械的含意判定はしない|未レビュー/承認/却下のリンクを分離。意味レビュー記録があっても含意を機械保証しない|
|矛盾|disagreementsへ併記、勝者を決めない、次の手がかり|登録済み反証/矛盾の確定宣言を拒否し次の資料・問い・理由を要求。未登録反証は発見できない|
|版・新資料|題名・年、既知資料、新着URL/日付|前回/今回の結論・状態・根拠集合の差。意味や改版本文差、因果は自動推論しない|

読んだ上流ファイルには構造化した原典依存グラフと結論before/after出力は見当たりませんでした。全履歴・全参照の網羅監査ではありません。これらの追加が調査品質全体を向上させるとの実測比較はまだありません。テスト件数で優位性を主張しません。

自作fixtureは、同原典の重複、目録の本文昇格、未レビューの支持表示、不正入力、循環、差分再現性を検査します。無関係な本文引用でも、正確に一致しているだけなら形式照合を通る場合があります。意味未レビューと表示して判断を残します。誤ったacceptedを自動で見抜くものではありません。

将来の比較は固定Imozuruを主対象、通常検索を補助対照にし、同一原資料・問い・事前資料・モデル・ツール・予算で実施します。方式名を伏せた評価で、重複計上、無関係引用、未解決矛盾の確定、前回結論差分、次の資料の有用性を原典へ戻って点検します。現時点では上流の実行比較も通常検索比較も未実施です。
